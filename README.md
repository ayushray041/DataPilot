
# DataPilot — AI-Powered Data Analyst

**Turn your data into useful insights with Python and AI.**

DataPilot is a web application that helps you explore datasets, calculate statistics, filter records, detect unusual observations, and create charts. You can also ask questions about your data in natural language using Google Gemini.

**Live Demo:** [Open DataPilot](https://datapilot-hxkzadjialx2k7hifgdtcm.streamlit.app)

**GitHub Repository:** [View the source code](https://github.com/ayushray041/DataPilot)

## What can DataPilot do?

DataPilot combines traditional Python data analysis with an AI assistant to make exploring datasets easier.

- **Explore datasets:** Upload a CSV or Excel file and inspect its rows, columns, data types, missing values, and duplicate records.
- **Profile your data:** Get a quick summary of the dataset and understand what each column contains.
- **Filter and sort records:** Find specific rows using text or numerical conditions, sort data, and limit the results.
- **Calculate statistics:** Find the mean, median, minimum, maximum, standard deviation, and quartiles of numerical columns.
- **Analyze correlations:** Measure the Pearson correlation between two numerical columns.
- **Create charts:** Generate bar charts, line charts, scatter plots, and histograms.
- **Detect anomalies:** Use Isolation Forest to identify observations that look unusual compared with the rest of the data.
- **Ask questions with AI:** Use natural language to request analysis. Gemini selects from DataPilot's registered Python tools, and the resulting information is used to prepare an answer.
- **Create charts without AI:** Generate visualizations directly from the dashboard without using a Gemini API request.

The dashboard includes an Overview tab, an AI Analyst tab, and a Visualizations tab. It also keeps conversation and chart results available across Streamlit reruns during the current session.

## How it works

DataPilot has three main parts:

1. **Streamlit frontend:** Lets users upload files, inspect their datasets, ask questions, and view results.
2. **Python analysis tools:** Use Pandas, Matplotlib, and scikit-learn to perform the actual calculations and generate charts.
3. **Gemini-powered agent:** Interprets a question, chooses a registered tool, executes it through the application, and uses the returned results to create a natural-language explanation.

The tool registry describes the available functions and their arguments. The Gemini adapter converts these descriptions into function declarations that the model can understand.

The agent executes only registered functions rather than running arbitrary Python code generated by the model.

## Getting started

### 1. Clone the repository

Make sure Git and Python 3.13 are installed.

Open a terminal and run:

```bash
git clone https://github.com/ayushray041/DataPilot.git
cd DataPilot
```

### 2. Create a virtual environment

On macOS or Linux:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
```

On Windows, you can create the environment with:

```powershell
py -3.13 -m venv .venv
.venv\Scripts\activate
```

### 3. Install dependencies

With the virtual environment activated, run:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 4. Configure Gemini

For local development, create a `.env` file in the project root, next to `requirements.txt`.

Add your own Gemini API key:

```dotenv
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-3.8-flash
```

Replace the placeholder with a valid API key. Keep `.env` private; it should never be committed to GitHub.

The model setting is configurable. If `GEMINI_MODEL` is omitted, DataPilot uses the default configured in `agent/llm.py`.

### 5. Start the application

From the project root, run:

```bash
python -m streamlit run app/streamlit_app.py
```

Streamlit will display a local URL to open in your browser.

Upload a CSV or Excel dataset from the sidebar. Explore the data in Overview, ask questions through AI Analyst, or create charts in Visualizations.

## Running the tests

Activate the virtual environment, move to the project root, and run:

```bash
python -m pytest -v
```

The tests cover the analysis tools, tool registry, and Gemini function-declaration construction.

To check a live Gemini API connection separately, run:

```bash
python -m tests.check_gemini_connection
```

This command makes a real API request, so it requires a valid API key, network access, and available Gemini quota. The ordinary unit tests should be run independently of this live connection check.

## Deploying on Streamlit Community Cloud

DataPilot can be deployed from its GitHub repository using [Streamlit Community Cloud](https://share.streamlit.io/).

Configure the application with:

- **Repository:** `ayushray041/DataPilot`
- **Branch:** `main`
- **Main file path:** `app/streamlit_app.py`

In the deployment's Secrets settings, configure your Gemini credentials:

```toml
GEMINI_API_KEY = "your_gemini_api_key_here"
GEMINI_MODEL = "gemini-3.8-flash"
```

Use your real key in Streamlit's private Secrets settings, not in this README or any public source file.

The local chart creator does not need a Gemini request. AI-powered questions, however, require valid credentials, network access, and available API quota.

## Limitations

- Gemini requests can fail when the API quota is exhausted, the key is invalid, or the service is unavailable.
- AI-generated explanations should be checked against the underlying data.
- Anomaly detection flags unusual observations; it does not prove that an observation is incorrect.
- Numerical analyses and charts require compatible data types and usable values.
- Reading legacy Excel `.xls` files may require the optional `xlrd` package in addition to the dependencies listed in `requirements.txt`.
